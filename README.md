# 🚀 Streamlit Projects

A collection of hands-on Streamlit projects developed while learning AI and Data Application Development using Streamlit. These projects cover Streamlit fundamentals, interactive widgets, data visualization, machine learning integration, API usage, authentication, and deployment. 0

## 📌 Projects Included

| Lab | Project |
|------|---------|
| Lab 1 | Hello Streamlit |
| Lab 2 | Widgets Playground |
| Lab 3 | Layouts (Columns, Sidebar, Tabs, Containers) |
| Lab 4 | Forms & Session State |
| Lab 5 | Data Visualization |
| Lab 6 | File Upload & Pandas |
| Lab 7 | Interactive Sales Dashboard |
| Lab 8 | Machine Learning Model Integration |
| Lab 9 | AI Chatbot Interface |
| Lab 10 | API Integration & JSON |
| Lab 11 | Git & GitHub Practice |
| Lab 12 | Streamlit Community Cloud Deployment |

| Capstone | Student AI Dashboard |

## ⚙️ Installation

```bash
git clone https://github.com/your-username/Streamlit-Lab-Projects.git

cd Streamlit-Lab-Projects

pip install -r requirements.txt
```

---

## ▶️ Run a Project

```bash
streamlit run app1_hello.py
```

Replace the filename with any project you want to run.
